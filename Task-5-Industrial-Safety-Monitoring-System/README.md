# Task 5 – Industrial Safety Monitoring System

## Problem Statement

Industrial environments face risks such as gas leakage, fire hazards, and abnormal temperature conditions.

## Objective

To develop an IoT-enabled Industrial Safety Monitoring System using ESP32.

## Components Used

* ESP32
* DHT11 Sensor
* MQ-2 Gas Sensor
* Flame Sensor
* Relay Module
* DC Fan
* Buzzer
* LEDs

## Features

* Real-Time Monitoring
* Gas Leakage Detection
* Fire Detection
* Temperature Monitoring
* Humidity Monitoring
* Automated Fan Control
* Safety Alerts
* Web Dashboard

## System Workflow

Sensors → ESP32 → Dashboard → Alert System

## Results

Successfully monitored environmental conditions and automatically responded to unsafe situations.
