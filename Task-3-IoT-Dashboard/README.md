# Task 3 – IoT Data Monitoring Dashboard

## Objective

To create a web-based dashboard for monitoring industrial sensor data.

## Features

* Temperature Monitoring
* Humidity Monitoring
* Gas Level Monitoring
* Real-Time Updates
* Alert Display

## Dashboard Output

The dashboard displays live environmental data and safety alerts using a web interface.
